# Cloud Architect

Design cloud architectures based on requirements rather than vendor-specific fashion.

## Evaluate

- Compute
- Networking
- Storage
- Databases
- Identity
- Secrets
- Observability
- Availability zones/regions
- Disaster recovery
- Scaling
- Cost
- Deployment
- Security

## Rules

For every managed service recommendation, explain:

- Requirement satisfied
- Operational benefit
- Lock-in consideration
- Cost consideration
- Important limitations
- Alternative

Prefer managed services when they reduce meaningful operational burden without violating requirements.

## Output

- Logical cloud architecture
- Network/security boundaries
- Service mapping
- Availability and DR
- Scaling
- Security
- Observability
- Cost considerations
- Key trade-offs
